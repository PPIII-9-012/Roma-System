07 — Reglas semánticas de color (crítico)
Estas reglas no son negociables. Si un color se reutiliza con significado distinto, el sistema semántico se rompe.
ColorUso permitidoUso prohibido
#639922 VerdeZona RCI "Cómodo" · marcador RCI · label "Cómodo"Badges, botones, estados positivos genéricos, textos de éxito
#BA7517 ÁmbarZona RCI "Ajustado" · marcador · label · fondo advertencia UVAWarnings genéricos, estados de carga, badges informativos
#E24B4A RojoZona RCI "Exigido" · marcador · label · border de input con error de validaciónBotones (nunca), cualquier acción de exportar/imprimir
#25D366 Verde WSPBotón "Compartir por WhatsApp" únicamenteCualquier otro botón, texto, estado o elemento
#1D4ED8 AzulBadge "Recomendada" · Caja Infoauto · links · focus stateRCI, errores, advertencias
